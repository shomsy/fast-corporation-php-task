## End-to-end coverage boundary

The normal browser path covers registration, login, authenticated Page A and B, native download, activity creation, user denial, logout, admin filtering and rendered reports. PHPUnit covers session, SQLite, failure, pagination and individual report semantics. Live HTTP acceptance verifies the same-origin JSON API, CSRF and accepted event counts. `FINAL-ACCEPTANCE.md` names exact executed gates. These local demonstrations do not certify external HTTPS, installed Nginx ingress, public data retention/legal basis, PHP-FPM capacity or off-host recovery objectives.
